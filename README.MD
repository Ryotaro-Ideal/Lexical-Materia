### まずはここから

## ゲームコンセプト（核）
**クラフトの概念を変えた、3D文字収集アクションゲーム**

例えば、従来のゲームで石の剣を作りたいとき、石と棒の２つの素材を拾う必要がある。

しかし、このゲームでは石、布、毛糸、金、を持ってるだけで石の剣を作れてしまう。
全く石の剣とは関係なさそうなモノなのになぜ？
→石、布、毛糸、金の４つの名前をじっくり見てみると、

1. 石→いし→"いし"
2. 布→ぬの→"の"
3. 毛糸→けいと→"け"
4. 金→きん→"ん"

上記のように4つの言葉を並び替えると「石の剣(いしのけん)」という言葉が完成する。
言葉遊びのようなクラフトシステムがこのゲームの特徴である。

## 概要
1. 「文字」を資源として扱うクラフト要素を中核に据えた、3Dアクション×クラフトゲーム。  
2. フィールド上に存在するさまざまなアイテムを集める。
3. 集めたアイテムは、文字分解という独自システムによって、アイテムの名前と同じ文字素材に分解できる。
4. その分解した文字素材を、クラフトの資源に落とし込み、全く別のアイテムをクラフトすることが可能。
5. アイテムの価値は名前に依存する。

---

## 制作意図
1. 元々、クラフトゲームが好きで、自分なりの面白さを加えたゲームを作りたいと考えて制作に至った。
2. 従来のクラフトゲームの強みは、リアリティの高いクラフトシステムによる没入感だと考えているが
3. その反面、レシピ通りのアイテムしか作れないという制約が、ゲームの選択肢の幅を狭めていると感じていた。
4. それを解決する手段として、一度アイテムをすべて文字に変えることで、なるべくクラフトの価値を平等化するシステムを考案した。
5. クラフトの価値を平等化することで、「正解ルート」が消える。
6. レシピ通りに作る達成感ではなく、「自分でルールを発見する」という喜びが生まれる。
7. 同じアイテムでも、プレイヤーによって全く異なる文字の使い方をする、この「攻略の個人差」こそが、繰り返し遊べる理由になると考えた。


---

## 基本ゲームループ
1. フィールドでアイテムを入手  
2. メニュー画面で、アイテムを文字素材に分解することで、アイテムの名前と同じ文字を入手
3. 必要な文字を消費して新たなアイテムをクラフト  
4. 装備や能力を強化し、新たなエリアを攻略

---

## クラフトシステム
- アイテム名と同じ文字素材を消費することでクラフトが成立  
- 例：  
  - 「木の斧」＝「き」「の」「お」「の」の文字素材が必要  
- 装備品にはランダム要素が存在し、ステータス補正や特殊効果が付与される場合あり  
- 不要になったアイテムは再分解可能（循環型設計）

## プレイヤー操作（プロトタイプ実装）
### 基本操作
- 移動：WASD  
- 視点操作：マウス  
- ダッシュ：Shift  
- ジャンプ：Space  
- 攻撃：LMB  
- メニュー：Tab  
- アイテムを拾う、調べる：E
